# coral-cli

`coral-cli` is a command-line tool for managing validator keys and interfacing with Puffer smart contracts

## Subcommands

#### `help`
Show help

#### `version`
Prints `coral-cli` version

#### `completions [SHELL]`
Output shell code necessary for a given shell to
auto-complete `coral-cli` commands

#### `validator`

See [validator](/coral-cli/docs/validator.md)
